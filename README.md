RugbyScore – Universal Rugby Scoring & Management App

RugbyScore is a modern, offline-first mobile application designed to help rugby teams manage players, matches, live scores, match results, and historical records.

The application is suitable for all types of rugby organizations, including university teams, school teams, rugby clubs, and national teams.

📱 About the Project
RugbyScore provides an easy and efficient way to manage rugby activities using a single mobile application.

Users can create multiple teams, register players, manage matches, record live scoring events, view match statistics, and retrieve historical match details even after several years.

The application works offline and stores data locally using SQLite.

✨ Key Features

🏆 Team Management
Create and manage multiple rugby teams.
Add team names, logos, country, and coach details.
Edit and delete team information.
View individual team profiles.

👥 Player Management
Register players under different teams.

🏉 Match Management

📊 Live Match Scoring
Record rugby scoring events in real time.

Try – 5 Points
Penalty Try – 7 Points
Conversion – 2 Points
Penalty Kick – 3 Points
Drop Goal – 3 Points

Live scoreboard.

🚀 Getting Started
Prerequisites
Install the following tools:

Node.js
npm
Git
Expo development environment
Android Studio (optional, for Android emulator testing)
Installation
1. Clone the repository
git clone [GITHUB_REPOSITORY_URL](https://github.com/pasinduchinthaka/RugbyScore.git)

2. Navigate to the project folder
cd RugbyScore

3. Install dependencies
npm install

4. Start the development server
npx expo start

Follow the Expo instructions to run the application on an emulator or compatible device.


🗄️ Data Storage
RugbyScore uses a local SQLite database to store:

Teams
Players
Matches
Match Events
Match Results
Historical Records
Completed match records are retained and can be retrieved through the historical archive.

Important: Since data is stored locally, users should regularly export backups. Uninstalling the app or losing the device may result in data loss if no backup exists.

🔒 Privacy

Match and team information is stored locally.

Users can manage their own team and match records.
